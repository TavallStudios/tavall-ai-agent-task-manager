# UNIVERSAL

This file defines universal response expectations for AgentTaskManager-assisted runs.

## Response Shape

- Lead with the concrete result (what changed, or what was found).
- Cite verification status clearly (what was run, what was not run).
- End with a short **Next Steps** section whenever there is follow-up work, risk, or a remaining decision.

## Next Steps Requirement

- If additional implementation, validation, rollout, or review is still required, list those next actions explicitly.
- If no follow-up is required, state that directly as `Next Steps: none`.
